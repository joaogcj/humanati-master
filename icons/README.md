# Humanati Icons

Sprite SVG complementar com seis ícones essenciais: `hu-home`, `hu-insights`, `hu-users`, `hu-check`, `hu-alert` e `hu-settings`.

Uso:

```html
<svg aria-hidden="true"><use href="sprite.svg#hu-home"></use></svg>
```

Todos os ícones usam `currentColor`, traço consistente e `viewBox` 24 × 24.
