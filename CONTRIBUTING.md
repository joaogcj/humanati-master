# Contribuindo com Humanati

Crie alterações pequenas e coesas. Preserve os arquivos históricos, reutilize o Design System e inclua documentação quando houver impacto de uso ou migração.

Antes de enviar uma alteração, execute `npm run validate`, `npm test` e `npm run build`. Use mensagens de commit no formato `tipo(escopo): descrição`, por exemplo `feat(ui-kit): adiciona estado de carregamento`.

Não inclua dados pessoais, credenciais ou materiais sem licença. Mudanças de marca devem seguir `documentation/BRAND_MANUAL.md`; mudanças estruturais devem registrar uma decisão em `documentation/adr/`.
